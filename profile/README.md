Code to turn a Mycroft Mark II into a private, offline voice assistant.

Repos will appear here as they're published. This is the project code for the assistant, not the Voice Controls YouTube examples (those live in [OhioIoT-Voice-Controls](https://github.com/OhioIoT-Voice-Controls)).
